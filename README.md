# Vibration Lite - Android Virtual Space & App Cloner

Ultra-lightweight Android virtual space container engineered for gaming and multi-instance apps.
- Package Name: com.vibration.lite
- Target APK Size: < 15MB
- Android 14 Compatibility
- Zero Ads, Zero Analytics, Zero Trackers

## Build Instructions
```bash
chmod +x gradlew
./gradlew assembleDebug
```
Output APK: app/build/outputs/apk/debug/app-debug.apk
